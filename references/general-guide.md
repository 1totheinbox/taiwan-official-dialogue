# 臺灣公文撰寫通用規則與用語使用時機指南（以行政院《文書處理手冊》112年6月8日修正版為準）

撰寫臺灣公文的最高準則是行政院《文書處理手冊》。現行版本由112年6月8日院臺綜字第1125010368號函修正，\[1\]行政院網站於112年9月20日公告，\[2\]俗稱「112年9月版」。用語選擇的核心邏輯是：先判斷你與受文者有無隸屬關係、誰高誰低（上行、平行、下行），再讓稱謂語（鈞／大／貴）、附送語（檢陳／檢送）、期望語（請鑒核／請查照）與署名方式彼此一致。\[1\]另外，自104年3月25日起，期望、目的及稱謂用語一律不再挪抬（空一格）。\[3\]\[4\]\[5\]

**流程說明**：本報告原定再交由校核工具逐句補充出處，但因篇幅超過工具上限而未執行。因此，報告中引用的行政院個別釋例，有部分是取自學校轉載的舊版彙編或教材的二手轉引（詳見第六節第6點）。

## TL;DR

- **規範依據**：以《公文程式條例》（最後修正96年3月21日）與《文書處理手冊》（112年6月8日修正）為主，輔以下列規範：
  - 《政府文書格式參考規範》（105年4月1日修正）
  - 手冊附錄的《法律統一用字表》《法律統一用語表》《標點符號用法表》《公文書橫式書寫數字使用原則》
  - 行政院持續更新的「文書處理相關釋例」
- **最易出錯的是期望語**：
  - 對有隸屬關係的上級：要上級審查決定時用「請鑒核／請核示」，只報請知悉時用「請備查／請鑒察」。
  - 對平行及下級用「請查照」，下級亦可用「希查照」。
  - 「核定」與「備查」在《地方制度法》第2條有法定定義，法律效果截然不同，不可互換。
- **寫完後依序核對五件事**：
  1. 行文方向是否判斷正確。
  2. 稱謂語與期望語是否同一方向。
  3. 主旨是否一段完成，且期望語未在說明或辦法段重複。
  4. 數字與用字是否合乎手冊附錄規範。
  5. 署名用印是否符合文別。

  手冊未規定的事項（例如自稱「職」、時間採12或24小時制、法規名稱是否加引號），以機關內規與行政院釋例為準，並維持全文一致。

- 行政院104年3月25日院臺綜字第1040127907號函：「自即日起有關公文之期望、目的及稱謂用語，均無須挪抬（空格）書寫。」\[18\]\[19\]\[20\]

## 二、公文類別與結構

### 1. 類別與使用時機（手冊第15點）

| 類別 | 使用時機 |
|---|---|
| 令 | 公布法律、發布法規命令、解釋性規定與裁量基準之行政規則、人事命令。令文不分段，動詞置於句首（訂定、修正、廢止）\[1\] |
| 呈 | 對總統有所呈請或報告\[1\] |
| 咨 | 總統與立法院、監察院公文往復\[1\] |
| 函 | 上對下指示、交辦、批復；下對上請求、報告；同級或不相隸屬機關間行文；民眾與機關間申請與答復\[1\] |
| 公告 | 向公眾或特定對象宣布周知\[1\] |
| 書函 | 公務未決階段的磋商、徵詢、通報；不涉准駁或解釋的簡單答復、寄送文件、一般聯繫查詢。正式性不如函，蓋條戳\[1\]\[22\] |
| 開會（會勘）通知單 | 召集會議或辦理會勘\[1\] |
| 公務電話紀錄 | 可用電話簡單正確說明的事項，必要時作成2份，雙方附卷\[1\] |
| 手諭 | 長官對所屬指示或交辦（舊稱手令） |
| 簽 | 承辦人員就職掌事項，或下級機關首長對上級機關首長，有所陳述、請示、請求、建議\[1\] |
| 報告 | 調查、研究、評估報告，或人員就個人事務陳請\[1\] |
| 箋函／便簽 | 以個人名義／以單位名義洽商或回復公務\[1\]\[24\] |
| 聘書、證明書、證書、契約書、提案、紀錄、說帖、定型化表單 | 依各自名稱用途使用 |
| 移文單、交辦（交議）案件通知單、催辦案件通知單 | 文書簡化工具（手冊第44、45點） |

### 2. 函與書函怎麼選

- 會產生權利義務或正式決定的，用**函**。
- 磋商、寄送資料、一般聯繫，或答復不涉准駁的，用**書函**。

### 3. 函的三段式寫法

**主旨**
- 說明行文目的與期望，力求具體扼要。\[1\]
- 不分項，一段完成，文字緊接段名冒號右側書寫。\[1\]\[7\]
- 有期限者，期限寫在主旨內。\[1\]
- 概括期望語（請核示、請查照、請照辦）只寫在主旨，不在辦法段重複。\[1\]\[25\]

**說明**
- 主旨無法容納事實、來源或理由時才使用。\[1\]
- 不分項時文字緊接冒號書寫；分項時另列縮格。\[1\]
- 復文或轉行時，應敘入來文的發文日期及字號。\[1\]

**辦法**
- 列舉具體要求。\[1\]
- 段名可依內容改為「建議」「擬辦」「公告事項」「核復事項」。\[1\]
- 內容繁雜或含表格時，改列附件。\[1\]

**段數與分項**
- 手冊明定：「可用1段完成者，不必湊成2段、3段。」\[1\]\[7\]\[26\]
- 分項標號依序為：一、→（一）→1、→（1）。標號以全形書寫，但括號用半形；每項只表達一個意思。\[1\]

### 4. 簽與稿的擬辦方式（手冊第19點）

| 擬辦方式 | 適用情形 |
|---|---|
| 先簽後稿 | 政策性或重大興革案件；牽涉較廣、會商未獲結論的案件；擬提決策會議的案件；重要人事案件；其他須先簽請核定者\[1\]\[7\] |
| 簽稿併陳 | 文稿內容須另為說明的案件；依法准駁但案情特殊者；須限時辦發、來不及先請示者\[1\]\[7\] |
| 以稿代簽 | 案情簡單或例行承轉的案件\[1\] |

- **先簽後稿**的簽，採「主旨、說明、擬辦」三段式。\[1\]
  - 「說明」段不提擬辦意見。\[1\]
  - 「擬辦」段提出具體方案，不重複說明內容。\[1\]
- **簽稿併陳**若案情簡單，可不分段，以條列方式撰寫。\[1\]
- **簽末用語**：機關內部單位簽辦的案件，簽末「不必敘明陳某某長官字樣」；下級機關首長對直屬上級機關首長，則得用「敬陳○○長官」。\[1\]

### 5. 公告與開會通知單

**公告**
- 分「主旨、依據、公告事項（或說明）」三段，段名前不冠數字。\[1\]
- 「依據」非必要不敘來文的日期與字號。\[1\]
- 公告沒有受文者、速別、正本、副本欄位。
- 張貼在公布欄的公告，蓋機關印信及首長職銜簽字章；登報或登載於電子公布欄者，免蓋印信，也免署首長名。\[1\]

**開會通知單**
- 欄位包括：事由、時間、地點、主持人、聯絡人及電話、出席者、列席者、副本、備註。\[1\]
- 蓋機關條戳。\[1\]

### 6. 行文方向的判斷

| 方向 | 判斷標準 | 稱謂 |
|---|---|---|
| 上行 | 有隸屬關係的下級對上級（例：國立大學對教育部） | 鈞\[9\] |
| 平行 | 同級或不相隸屬機關之間、機關與人民之間（例：國立大學對市立高中） | 貴\[9\] |
| 下行 | 有隸屬關係的上級對下級（例：縣政府對縣立國中小） | 貴 |
| 無隸屬的較高機關 | 行政機關對立法院、監察院等 | 大\[27\] |

- 關鍵在於有無「隸屬關係」，而不是機關大小。
- 縣（市）政府教育處是府內單位，不能列為受文者，應寫該縣（市）政府。\[9\]

### 7. 欄位填寫（手冊第31、41、47點）

- **速別**：分最速件、速件、普通件；限期公文不必填。處理時限分別為1日、3日、6日。\[1\]
- **密等**：國家機密分絕對機密、極機密、機密；一般公務機密為「密」。解密條件以括弧標於等級右側，例如「（本件於公布時解密）」。\[1\]
- **附件**：註明名稱、媒體型式、數量；兩種以上時標示附件1、附件2。附件以隨正本附送為限，副本若也附送，應在副本受文者名稱右側註明「含附件」。\[1\]
- **正本／副本**：主體機關或通案分行的機關列正本；有關聯的機關列副本。若要求副本收受者辦理某事，應在說明段寫明。副本若僅屬通知性質，不必答復。\[1\]\[22\]
- **發文字號**：文號共11碼，前3碼為年度、中間7碼為流水號、最後1碼為支號。發文字號每年更換一次。\[1\]\[7\]
- **檔號、保存年限**：寫在首頁右上方。\[8\]

### 3.2 稱謂語（手冊第18點）

**直接稱謂**

| 對象 | 稱對方 | 自稱 |
|---|---|---|
| 有隸屬關係，上對下 | 貴 | 本\[7\] |
| 有隸屬關係，下對上 | 鈞 | 本\[7\] |
| 無隸屬關係，對上級 | 大 | 本\[7\] |
| 無隸屬關係，平行 | 貴 | 本\[7\] |
| 機關首長之間，上對下 | 貴 | 本 |
| 機關首長之間，下對上 | 鈞長 | 本 |
| 機關或首長對屬員 | 臺端 | 本 |
| 對人民 | 先生、女士，或通稱君、臺端 | 本\[9\] |
| 對團體 | 貴 | 本 |
| 一文行數機關 | 貴機關、貴單位 | 本 |

**間接稱謂**
- 對機關、團體稱全銜或簡銜；一再提及時，必要時可稱「該」。\[1\]\[28\]\[29\]
- 對職員稱職銜。\[1\]\[28\]\[30\]
- 對個人一律稱先生、女士或君。\[1\]\[28\]\[29\]
- 引述他文時，應把「貴」「鈞」改為「○○」「本」「該」（手冊第16點（二）7）。\[1\]

**注意事項**
- 「台端」應寫為「臺端」（105年12月27日釋例）。\[7\]\[9\]
- 「鈞座」屬舊稱，手冊只列「鈞長」。
- 自稱「職」，手冊無規定，屬於慣例，常見於屬員對長官的簽或報告；機關之間的函一律自稱「本」，不用「敝」。\[23\]\[29\]\[31\]

**鑒核、核示、核備、備查、查照、鑒察的區辨**

| 用語 | 對方要做什麼 | 事項何時生效 |
|---|---|---|
| 鑒核 | 審查並作決定 | 上級決定後才生效，相當於報請「核定」\[9\] |
| 核示 | 審核並指示 | 上級指示後才能辦理\[9\] |
| 核備 | 審查內容，合法即存查，違法可駁回 | 無法律定義，依個別法規解釋 |
| 備查 | 只需知悉 | 下級已依法完成效力\[9\] |
| 鑒察 | 察閱瞭解 | 已辦理完畢 |
| 查照 | 平行或下級查明知照 | 發文機關已生效\[9\] |

- **核定**：《地方制度法》第2條第4款定義為「上級政府或主管機關，對於下級政府或機關所陳報之事項，加以審查，並作成決定，以完成該事項之法定效力之謂」。\[34\]\[46\]\[47\]
- **備查**：同條第5款定義為「下級政府或機關間就其得全權處理之業務，依法完成法定效力後，陳報上級政府或主管機關知悉之謂」。保訓會教材說明，備查「即使未踐行此項程序，亦不影響該事項之法律關係或效力」。\[46\]\[48\]
- **兩者不可互換**：法務部102年法規諮詢意見指出，核定與備查「目的、程序及法律效果均不同，如法規明定某事項應由上級機關或主管機關核定者，自不得以備查程序代替，否則不生核定法律效果」。\[49\]
- **核備**：無法律定義。保訓會教材解釋為上級「除知悉其事實外，並可審查其內容」；最高行政法院則曾將人民團體法第54條的「核備」認定為備查性質的觀念通知。\[48\]\[50\]\[51\]
- **實務原則**：法規怎麼寫，期望語就怎麼寫，不要自行升降。法規寫「報請核定」就用「請鑒核」；寫「報請備查」就用「請備查」；寫「核備」就用「請核備」。

**期望語常見錯誤**
1. 下級請示上級用「請核復」，應改為「請核示」或「請鑒核」。\[18\]\[43\]
2. 對受文者沒有特別要求時寫「請查照辦理」，應只寫「請查照」。\[18\]
3. 上級徵詢意見，下級函復時用「請卓參」，應改為「請鑒核」。\[18\]
4. 在說明段或辦法段重複寫期望語。\[18\]\[25\]\[45\]
5. 「惠請」疊用：101年10月29日釋例指出，「惠」與「請」都是請求的敬詞，「毋須同時使用」。\[7\]\[9\]
6. 用「至紉公誼」「為禱」「無任感禱」等書信應酬語作期望語。\[9\]
7. 具強制性的要求卻寫成「請協助配合」，應直接寫明應辦事項。\[18\]
8. 主旨已清楚寫出期望事項時，不必再加「請查照」（109年6月18日釋例）。\[52\]

### 3.10 法律統一用語（手冊附錄2）與數量界限

- **制定／訂定**：法律用「制定」，行政命令用「訂定」；書表證照等用「製作」。\[1\]
- **設／置**：機關用「設」，人員用「置」。\[1\]
- **條次寫法**：寫「第九十八條」「第一百條」「第一百十八條」，不寫「第九八條」「第一００條」「第一百一十八條」（法制作業公文用中文數字）。\[1\]
- **施行用語**：寫「自公布日施行」。\[1\]
- **處／科**：自由刑、罰鍰用「處」；罰金用「科」。不寫「之罰金」。\[1\]
- **引用條文**：引用本法其他條文，不必寫「本法」；引用本條其他項，不必寫「本條」。\[1\]
- **數字書寫**：序數不用壹、貳、參；「零」「萬」不寫作「０」「万」。\[1\]
- **數量界限**：
  - 「以上、以下、以內」包含本數（刑法第10條第1項：「俱連本數或本刑計算」）。法務部103年12月19日法律字第10303514570號函釋指出，「一定歲數以下」不包括已滿該歲數者。\[55\]\[56\]
  - 「逾、超過、未滿」不含本數。\[57\]
  - 「以前、以後」是否含當日，法律未明定，公文中宜寫明「（含）」。\[57\]

### 4.2 標點符號（手冊附錄3）

- **請示語**：「是否可行，請核示。」用逗號，不用問號。\[54\]
- **法規名稱的引號**：
  - 法律、法規命令：手冊99年起的作法是不加引號。\[9\]
  - 行政規則（要點、須知、計畫、簡章等）：加引號。\[9\]
  - 106年4月24日釋例澄清，手冊「並無規範，各機關可本於權責自行決定，惟應力求一致」。\[7\]
- **全形與半形**：中文及併用的標點用全形；阿拉伯數字、外文字母用半形。\[1\]

### 4.3 挪抬與側書

- **挪抬**：104年3月25日以後不空格。\[59\]
- **側書**：自稱「職」縮小偏右，屬傳統禮儀，手冊無規定。電腦繕打時可改用較小字級，或依機關慣例處理。\[23\]\[31\]

### 4.4 日期、法條、名稱

- **日期**：用國曆「中華民國○年○月○日」；外文或譯件可用西元。\[1\]發文日期欄已有「中華民國」，本文中不必重複年號。\[7\]\[9\]
- **法條**：寫「○○法第○條第○項第○款」。
- **機關名稱**：首次寫全銜，其後可用簡銜或「該」；非習用的名稱不要省文縮寫；多個機關並列時依既定順序由左至右排列。\[1\]
- **人名**：不要斷在兩行。\[23\]

### 4.5 寫作原則

- **簡、淺、明、確**：公文程式條例第8條。手冊第16點列出的作業要求為正確、清晰、簡明、迅速、整潔、一致、完整。\[1\]\[7\]
- **一文一事**：來文一文數事者，得分數文答復。\[1\]
- **具體表態**：不得用「可否照准」「究應如何辦理」等語空言敷衍；簽辦時不得只寫「陳核」「請示」。\[1\]
- **語氣**：不卑不亢，不用「卑職」「竊職」，避免陳腐套語與俗語。\[23\]

### 4.6 署名與用印（手冊第40點；公文程式條例第3、4條）

| 文別 | 署名用印方式 |
|---|---|
| 令、公告、聘書、證明書、獎狀等 | 機關印信加首長職銜簽字章\[1\]\[21\]\[28\] |
| 呈 | 首長全銜、姓名，蓋職章\[1\]\[21\]\[28\] |
| 上行函 | 署首長職銜、姓名，蓋職章\[7\] |
| 平行、下行函 | 蓋職銜簽字章\[60\] |
| 書函、開會通知單、移文單、事務性通知 | 蓋機關或單位條戳\[1\]\[7\] |
| 單位主管依授權對外行文 | 署名並蓋職章，或蓋條戳\[1\]\[22\] |
| 電子交換公文 | 得不蓋用印信或簽署\[7\]\[22\]\[61\] |

- **代理**：首長出缺時，由代理人署名。\[61\]
- **代行**：首長因故不能視事時，署首長姓名並註明事由，由代行人附署職銜、姓名，加註「代行」。\[1\]105年6月14日釋例指出，是否在勤以發文當日為準。\[7\]
- **分層負責代為決行**：仍以機關名義、首長署名。內部決行欄蓋職名章及「代為決行」章，或註明「代判」。\[62\]部分機關（例如臺北市、高雄市政府）另在簽字章下加註「本案依分層負責規定授權○○決行」。\[63\]\[64\]\[65\]細節依各機關文書處理要點。
- **騎縫章與頁碼**：公文兩頁以上時，騎縫處蓋騎縫章，並加註置中頁碼。\[1\]\[7\]\[35\]

### 4.7 版面規格（《政府文書格式參考規範》105年版）

- **紙張**：A4直式，70～80GSM，由左至右橫式書寫。\[8\]
- **邊界**：上、下、右緣各2.5公分；左緣2.5公分，裝訂線距左緣1.5公分。\[8\]
- **字型**：中文用楷書，英文及數字用Times New Roman。\[8\]
- **函的字級**：
  - 機關全銜加文別：20點，置中。\[8\]
  - 受文者、主旨、說明：16點。\[8\]
  - 地址、日期、字號、速別、附件、正副本：12點。\[8\]
  - 頁碼：10點。\[8\]
- **行距**：16點字的行距為28點±4點。\[8\]
- **電子化**：公文得採線上簽核（手冊第8點）；適合電子交換者，應以電子交換行之；周知性公文以登載機關電子公布欄為原則。\[1\]

### 4.8 初學者與國家考試常見失分

1. 主旨分項、冗長，或照抄題目。\[66\]
2. 行文方向判斷錯誤，連帶稱謂、期望語、附送語、署名全部錯誤。
3. 稱謂與期望語方向不一致，例如「鈞部……請查照」。
4. 期望語在說明段或辦法段重複。
5. 用「請核復」「請卓參」回復上級。
6. 仍在期望語、稱謂語前空格。
7. 數字寫錯，例如「第五屆」「乙份」「附件一」「（三）」。\[9\]
8. 法律統一用字寫錯，例如「計劃書」「部份」「身份」「佔」「台端」。
9. 使用「等因奉此」「為禱」「至紉公誼」等套語。
10. 說明段沒寫來文日期與字號；擬辦段重複說明內容。
11. 辦法段空泛，沒有寫出期限與窗口。
12. 涉及准駁的事項卻用書函。

## 五、範例

### 範例一：上行函（國立大學→教育部）

> **國立○○大學　函**
> 受文者：教育部
> 發文日期：中華民國115年11月10日
> 發文字號：○○字第1150012345號
> 速別：普通件
> 密等及解密條件或保密期限：
> 附件：本校「116年度學生服務學習推動計畫」1份
>
> 主旨：檢陳本校「116年度學生服務學習推動計畫」1份，請鑒核。
> 說明：
> 一、依鈞部115年9月15日臺教學(二)字第1150098765號函辦理。
> 二、本計畫業經本校115年10月28日115學年度第1次行政會議通過，預計補助經費新臺幣（以下同）50萬元，本校自籌20萬元。
> 三、本計畫如奉核定，將自116年2月1日起實施。
>
> 正本：教育部
> 副本：本校學生事務處（含附件）
>
> 校長　○○○（蓋職章）

用語選擇理由：
- 國立大學隸屬教育部，屬上行文，所以用「檢陳」「鈞部」「依」。
- 計畫須經上級審查決定才生效，所以用「請鑒核」，不用「請備查」。
- 上行函署首長姓名並蓋職章。

### 範例二：平行函（國立大學→市立高中，復函同意）

> **國立○○大學　函**
> 受文者：臺北市立○○高級中學
> 發文日期：中華民國115年11月10日
> 發文字號：○○字第1150012399號
> 速別：普通件
> 密等及解密條件或保密期限：
> 附件：
>
> 主旨：貴校申請借用本校體育館辦理校慶活動一案，敬表同意，復請查照。
> 說明：
> 一、復貴校115年11月3日北市○○學字第1150004567號函。
> 二、借用時間為115年12月5日（星期六）上午8時至下午5時，場地清潔費新臺幣3,000元，請於11月28日前逕洽本校體育室繳納。
> 三、本案聯絡人：體育室○○○先生，電話（02）○○○○-○○○○。
>
> 正本：臺北市立○○高級中學
> 副本：本校體育室
>
> 校長　○○○（職銜簽字章）

用語選擇理由：
- 兩校無隸屬關係，屬平行文，稱「貴校」。
- 平行機關表示同意，用「敬表同意」，不用「准予」。
- 「一案」屬描述性用語，用中文數字。\[7\]
- 使用標準復文句「復貴校……函」；時間採12小時制並冠上午、下午。
- 平行函蓋職銜簽字章。

### 範例三：下行函（縣政府→所屬學校）

> **○○縣政府　函**
> 受文者：本縣各公立國民中小學
> 發文日期：中華民國115年11月10日
> 發文字號：府教學字第1150234567號
> 速別：速件
> 密等及解密條件或保密期限：
> 附件：「○○縣校園防災演練實施計畫」及成果填報表各1份
>
> 主旨：請於115年12月15日前完成校園防災演練並填報成果，請照辦。
> 說明：
> 一、依教育部115年10月20日臺教資(六)字第1150123456號函辦理。
> 二、檢送「○○縣校園防災演練實施計畫」及成果填報表各1份。
> 辦法：
> 一、各校應依實施計畫第4點規定，擇定演練日期並通知家長。
> 二、演練成果請於115年12月20日前上傳本府教育處填報系統，逾期未填報者，列入年度校務評鑑扣分項目。
> 三、本案聯絡人：教育處學管科○○○小姐，電話（0○）○○○○-○○○○。
>
> 正本：本縣各公立國民中小學
> 副本：本府教育處
>
> 縣長　○○○（職銜簽字章）

用語選擇理由：
- 縣府對所屬學校屬下行文。
- 要求對方執行，用「請照辦」（也可用「希照辦」）；期限寫在主旨。
- 下行附送用「檢送」；用「應」表示強制。
- 教育處是府內單位，列為副本。
- 下行函蓋職銜簽字章。

### 範例四：簽（大學內部，先簽後稿）

> **簽**　於學生事務處課外活動組　115年11月10日
>
> 主旨：為辦理本校116年度寒假偏鄉服務隊出隊，擬補助交通及保險費用新臺幣12萬元，簽請核示。
> 說明：
> 一、依據本校「學生社團活動補助要點」第5點規定辦理。
> 二、本處前於115年10月1日公告受理申請，計有4個社團提出申請，業經115年11月5日審查會議審查完竣，會議紀錄如附件1。
> 三、經查本年度學生活動費尚有餘額新臺幣35萬元，足以支應。
> 擬辦：
> 一、擬依審查結果補助4隊，每隊新臺幣3萬元，所需經費自本處115年度學生活動費項下支應。
> 二、如奉核可，擬函請各服務地點學校惠予協助，並將出隊名冊送體育室辦理保險。
>
> 會辦單位：主計室
>
> 敬陳
> 學務長
> 　　　　　　職　○○○（蓋職章）謹簽

用語選擇理由：
- 涉及經費，所以採先簽後稿的三段式；主旨用「簽請核示」。
- 說明段只陳述事實，不寫意見；擬辦段寫出具體金額與經費來源。
- 經費案須會辦主計室。
- 「敬陳　學務長」與自稱「職」是校內慣例。手冊規定內部單位簽辦的案件「不必敘明陳某某長官字樣」，是否寫上依各校規定。

## 六、說法分歧與注意事項

1. **「請查照」用於平行還是下行**：各考試答案歸類不一。\[67\]行政院107年6月22日院長電子信箱釋例指出，「請查照」在實務上常見於平行文及下行文；\[9\]111年3月11日釋例也認定兩種方向皆可。\[34\]\[68\]
2. **「請察照（詧照）」**：保訓會教材建議用於答復監察院等無隸屬關係的上級機關。\[18\]但行政院107年6月22日釋例指出手冊對此「並無規範」，並舉例實務上法務部行文立法院也使用「請查照」。\[34\]\[45\]最保險的寫法是「請查照」。
3. **「請備查」的行文方向**：部分學校網頁將其列為平行或下行用語。但依《地方制度法》第2條，備查是向上級陳報知悉，應屬上行用語。\[46\]
4. **「惠復」**：各教材說法有出入。行政院只針對「惠請」作出釋例，建議在「見復」與「惠復」中擇一使用，不要疊加敬詞。\[7\]\[9\]
5. **平行函的蓋章方式**：104年版手冊規定「蓋職銜簽字章或職章」，\[7\]112年現行版改為「平（下）行文蓋職銜簽字章」，以現行版為準。\[1\]\[21\]\[28\]\[35\]
6. **釋例的版本與出處**：行政院網站最新列示的是「115.11.2更新」版釋例，但其PDF本次無法讀取。\[11\]本報告引用的101至112年各則釋例，取自學校轉載的舊版彙編（例如106.10.12版、112.8.29版），或教材的二手轉引；其中96.6.28、112.5.30、112.6.9各則未核對原件。新版是否仍保留這些條目，請下載行政院最新版確認。
7. **手冊未規定、屬慣例的事項**：自稱「職」、側書、時間採12或24小時制、法規名稱是否加引號，原則上維持全文一致，並從機關內規。\[23\]

## 七、快速查核清單

**A. 文別與方向**
- [ ] 文別選對：准駁或正式決定用函；聯絡、寄送資料用書函；召集會議用開會通知單；內部請示用簽。
- [ ] 行文方向判斷正確：有隸屬關係的上級為上行，同級或無隸屬為平行，有隸屬關係的下級為下行，無隸屬的國會、院級機關稱「大」。
- [ ] 受文者是機關，不是機關內部單位。

**B. 用語一致**
- [ ] 稱謂：上級用「鈞」，無隸屬的較高機關用「大」，平行與下級用「貴」，人民用先生、女士、君、臺端；自稱「本」。
- [ ] 附送：上行用「檢陳」，平行與下行用「檢送」或「檢附」。
- [ ] 引述：上行用「依」與「奉悉」，平行用「依據」與「敬悉」，下行用「依據」與「已悉」。
- [ ] 期望語：上行用請鑒核、請核示、請核備、請備查；平行與下行用請查照、請照辦、請辦理見復、請轉行照辦。
- [ ] 准駁語：平行用敬表同意、歉難同意；下行用准予……、未便照准，駁回時附理由。
- [ ] 鑒核（核定）與備查沒有混用，且與所依法規的用語一致。
- [ ] 沒有「惠請」「請核復」「為禱」「至紉公誼」「等因奉此」。
- [ ] 期望語與稱謂語前沒有空格。

**C. 結構**
- [ ] 主旨一段完成、不分項；期限寫在主旨；句型為「……，請○○。」
- [ ] 期望語只出現在主旨。
- [ ] 說明段寫出依據來文的機關、日期、字號；簽的說明段不寫意見。
- [ ] 辦法或擬辦段具體，寫出期限、窗口，且不重複說明內容。
- [ ] 能用一段或兩段完成的，沒有硬湊三段。
- [ ] 分項依序為一、（一）、1、（1），每項一意，括號用半形。

**D. 文字與數字**
- [ ] 日期、序數、份數、金額、時間、條次用阿拉伯數字；描述性用語、專有名詞、慣用語、「一案」「一式」用中文數字。
- [ ] 金額冠「新臺幣」並加千分位逗號；時間制全文統一，並寫「星期○」。
- [ ] 統一用字正確：公布、部分、身分、占、牴觸、計畫／規劃、紀錄／記錄、儘量、澈底、臺端、聲請／申請。
- [ ] 並與併、須與需、應與得、及與與用對；不用「暨」作連接詞；寫「其他」不寫「其它」。
- [ ] 「以上、以下」含本數，「逾、未滿」不含本數；日期界限寫明是否含當日。
- [ ] 標點用全形；不用【】《》～；請示語後用逗號。

**E. 欄位與格式**
- [ ] 速別、密等（含解密條件）、附件（名稱、數量、編號）、正本、副本（含附件時註明）均已填寫。
- [ ] 發文字號、檔號、保存年限已填。
- [ ] 版面：楷書加Times New Roman；全銜20點、本文16點、欄位12點；A4紙、邊界2.5公分。
- [ ] 署名用印：上行函署名並蓋職章；平行與下行函蓋職銜簽字章；書函與通知單蓋條戳；兩頁以上蓋騎縫章並加頁碼。
- [ ] 最後通讀一遍：簽稿是否相符，名稱、數字、錯別字、措詞是否得當（手冊第34點閱稿要項）。\[1\]
